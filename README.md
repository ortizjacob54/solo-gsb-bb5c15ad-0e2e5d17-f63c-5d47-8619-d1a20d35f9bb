# 平面照片标尺校准 Web 应用

上传一张包含**已知实际宽 × 高矩形参照物**（信用卡、打印矩形、标定框等）的平面照片，
依次标记矩形四角后，系统通过**四点 DLT 单应矩阵**完成透视校准；随后可在照片上
绘制一个或多个闭合多边形作为**外轮廓**，并在每个外轮廓内部继续绘制**多个镂空孔洞**，
实时得到**校正后的实际净面积与总周长**。

- 区域**净面积** = 外环面积 − 全部孔洞面积；**总周长** = 外环周长 + 全部孔洞周长
- 孔洞必须**完全位于外环内**；孔洞与外环、孔洞与孔洞之间**不得相交或相切**
  （也不允许相互嵌套）；所有环关系都在**校正后的实面坐标**上校验
- 拖动外环 / 孔洞任一顶点时实时重算；非法状态显示具体冲突（哪条边与哪条边、
  哪个顶点越界），并保留**服务端最后一次有效结果**不被覆盖
- **标定敏感性评估**：对四个角点施加统一像素误差半径的 **128 组可复现扰动**，
  逐组重解单应矩阵并复测全部区域，给出面积 / 周长的 **P5 / P50 / P95** 区间与
  有效样本覆盖率；退化、越界、几何非法样本一律计入失败比例，**有效比例低于
  80% 时不显示区间**并提示重新标定

- 后端：FastAPI（Python 3.11），NumPy 求解/校验 3×3 单应矩阵
- 前端：原生 HTML / CSS / JavaScript，Canvas 渲染，零构建、零前端框架
- 所有几何点以**原始图像像素坐标**存储，缩放 / 平移 / 拖动顶点不改变测量几何
- 前后端使用同一套数值算法（镜像实现），浏览器实时预览，服务器权威复核

## 一条命令启动

需要 Docker（含 Compose 插件）：

```bash
docker compose up -d --build
```

然后在浏览器打开：

> **http://localhost:8000**

端口：宿主机 **8000** → 容器 8000（在 `docker-compose.yml` 的 `ports` 中可改）。
上传的图片与会话保存在宿主机 `./data` 目录（挂载卷），容器重启后仍然存在。

> 持久化与会话兼容：区域（含孔洞环）以 JSON 保存在 `data/sessions/`。
> 升级前保存的**旧会话没有孔洞字段，加载时自动按“无孔洞区域”处理**，
> 旧测量结果不受影响。

停止：

```bash
docker compose down
```

## 本地直接运行（不用 Docker）

```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

访问 http://localhost:8000 。

## 使用步骤

1. **上传照片**：点击右上角按钮，或将图片拖入页面（EXIF 方向会被自动纠正）。
2. **透视标定**：
   - 在侧栏填入参照物的**实际宽、实际高与单位**（mm / cm / m / in / px）；
   - 按 **左上 → 右上 → 右下 → 左下** 的顺序在图上单击四角（与矩形在照片中
     的实际朝向无关，顺序一致即可）；
   - 角点可随时**拖动微调**，标定实时重新计算，有效时四边形变为绿色。
3. **绘制区域**：切换到“绘制外环”模式，逐点单击多边形顶点；
   - **双击 / Enter / 点击第一个顶点**闭合；
   - `Esc` 取消当前草稿，`Backspace` 撤销最后一个顶点；
   - 可绘制任意多个外轮廓区域。
4. **添加镂空孔洞**：选中一个区域后切换到“镂空孔洞”模式（快捷键 `5`），
   在该外环内部像画外环一样逐点单击、双击闭合，可添加任意多个孔洞；
   - 孔洞必须**完整落在外环内**，与外环边界、其它孔洞均**严格分离**
     （相交、相切、过近、相互嵌套都会被拒绝，提示精确到冲突的边 / 顶点）；
   - 结果卡片中可查看每个孔洞的面积、周长，并用 ✕ 单独删除孔洞。
5. **查看与编辑**：
   - 右侧实时显示每个区域校正后的**净面积、总周长**（以及外环毛面积、孔洞数），
     可切换结果显示单位（mm² / cm² / m² / in² / px²，按长度单位平方自动换算）；
   - “编辑”模式可拖动**外环顶点（圆点）、孔洞顶点（菱形）**，或拖动整个区域
     （外环与孔洞一起平移），**右键顶点删除**（孔洞不足 3 点时删除整个孔洞）；
   - 拖动过程中前端实时校验：若当前几何非法，数字变为 “—” 并列出冲突；
     松手后服务端再次权威校验，非法编辑返回 **422**、不写盘，界面自动回退到
     **最后一次有效结果**（也可点卡片上的“恢复到上次有效”手动回退）；
   - 每个区域可重命名、单独删除；“清空区域”一键全部重画。
6. **标定敏感性评估**（可选）：在“透视标定”面板填**角点误差半径 (px)**，
   点击「评估敏感性」——后端对四角施加 128 组固定扰动并逐组重算，
   每个区域卡片显示面积 / 周长的 **P5–P95 区间**与有效样本覆盖率；
   覆盖率低于 80% 时区间隐藏并提示重新标定。角点、误差半径或区域一旦变化，
   旧评估结果自动作废，需重新评估。
7. **导出**：点击“导出 JSON”，下载本次全部测量结果（含单应矩阵、图像坐标、
   校正后坐标、外环与每个孔洞的面积周长、净面积及校验状态）。

## 什么时候会阻止计算（以及原因）

校准与测量在**前端实时拦截**并由**后端再次权威校验**，错误信息直接显示在界面上：

- 角点重合、三点共线、四点不构成凸四边形（顺序错乱/自交）→
  *“四个角点没有构成凸四边形（顺序错乱或自交），请按 左上→右上→右下→左下 依次点击”*；
- DLT 方程组秩亏损（四点共线等退化情况）→
  *“透视变换不可逆：标定四点共线或构成退化四边形，无法从平面照片恢复唯一映射”*；
- 单应矩阵行列式接近 0，或某点映射到无穷远线（齐次分母 ≈ 0）→
  *“透视矩阵行列式接近 0，变换不可逆……”* / *“……映射时分母接近 0（落在无穷远线上）”*；
- 标定对应残差过大（角点与已知矩形对不上）→
  *“透视校准残差过大……请检查点击顺序”*；
- 多边形顶点重合或**边自交** →
  *“多边形自交（边 i 与边 j 相交），自交多边形没有唯一的面积，请调整顶点”*；
- 孔洞与外环边相交 / 接触，或孔洞伸出外环 →
  *“孔洞 k 与外环相交或相切（外环边 i 与孔洞边 j）……”* /
  *“孔洞 k 没有完全位于外环内（孔洞顶点 n 位于外环之外）”*；
- 两个孔洞相交 / 相切 / 距离过近 / 相互嵌套 →
  *“孔洞 i 与孔洞 j 相交或相切（边 p 与边 q）……”* /
  *“孔洞 j 位于孔洞 i 内部（孔洞不允许相互包含）”*；
- 多边形 / 孔洞顶点经透视变换后落在无穷远线附近 →
  *“多边形顶点 k / 孔洞 h 顶点 k 的透视分母接近 0……无法计算校正后坐标”*。

上述检测都在**校正后的实面坐标**上进行（图像像素坐标里的“相切”经透视校正后
未必相切，反之亦然），前端实时校验与后端权威校验使用同一套镜像算法。

数值阈值集中在 `backend/app/geometry.py` 与 `frontend/app.js` 顶部的常量中
（重合、共线、主元、残差、行列式、分母容差），两处保持一致。

## 导出 JSON 结构

```json
{
  "schema": "photo-ruler/1.0",
  "exported_at": "2026-09-19T08:11:43Z",
  "session_id": "…",
  "image": { "filename": "….jpg", "width": 800, "height": 600 },
  "calibration": {
    "corners": [{ "u": 0, "v": 0 } /* …4 个图像像素角点 */],
    "rect_width": 85.6, "rect_height": 53.98, "unit": "mm",
    "homography_image_to_world": [[/* 3×3 */]],
    "valid": true, "errors": []
  },
  "all_measurements_valid": true,
  "polygons": [
    {
      "name": "带孔区域",
      "image_points": [{ "u": 150, "v": 150 } /* …外环顶点 */],
      "world_points": [{ "x": 7.13, "y": 6.75 } /* …外环校正后坐标 */],
      "area": 353.1895,
      "gross_area": 433.1895,
      "perimeter": 123.45,
      "holes": [
        {
          "index": 1,
          "image_points": [{ "u": 200, "v": 200 } /* …孔洞图像像素顶点 */],
          "world_points": [{ "x": 9.1, "y": 8.2 } /* …孔洞校正后坐标 */],
          "area": 80.0,
          "perimeter": 40.0
        }
      ],
      "valid": true, "errors": []
    }
  ]
}
```

`area` 为净面积（外环 `gross_area` − 全部孔洞 `area` 之和）；`perimeter` 含外环
与所有孔洞边界。`holes` 为空数组 `[]` 时即没有孔洞的普通区域——**旧会话导出的
JSON 中可能没有 `holes` / `gross_area` 字段，加载时按无孔洞处理**。
面积/周长单位为标定所填单位（其平方）。`all_measurements_valid=false` 表示
标定或至少一个区域（外环或任一孔洞关系）无效，对应条目的 `errors` 给出原因。

## 算法说明

- 设图像点 `p=(u,v,1)`、实面坐标 `X=(x,y,1)`，映射 `X ∼ H p`。
- 4 对点给出 8 个线性方程（DLT），对两组点做各向同性归一化后以 SVD
  （后端 NumPy）/ 完全选主元 Gauss-Jordan（前端，无第三方库）求零向量，
  再反归一化得到 `H`。
- 校验链：点重合 → 凸性（叉积同号）→ 主元/秩 → DLT 残差 →
  `|det H|` → 逐点齐次分母。
- 多边形：各顶点经 `H` 变换到实面后做自交检测（非相邻边跨立试验），
  再以鞋带公式求面积（取绝对值）、边长累加求周长。
- 镂空区域：外环与每个孔洞都先各自变换到实面并做自交检测；随后在实面坐标上
  逐对检查外环边 × 孔洞边、孔洞边 × 孔洞边的关系——严格相交（跨立试验）、
  顶点落在对方边上（相切）、平行边间距小于相对容差（近相切）均判非法；
  再以射线法确认每个孔洞顶点严格位于外环内、且任意两洞互不包含。
  净面积 = 外环鞋带面积 − Σ 孔洞鞋带面积，总周长 = 外环周长 + Σ 孔洞周长。

## 标定敏感性评估

标定角点的点击误差会经单应矩阵放大到每一次测量。给定四个角点**统一的像素
误差半径**后（`POST /api/sessions/{id}/sensitivity`，请求体
`{"radius_px": 2.0}`，范围 0–1000）：

- 后端按当前标定几何（四角 + 矩形宽高）以 SHA-256 种子生成 **128 组可复现
  扰动**（同一几何 → 同一批扰动 → 同一份报告；误差半径只缩放这组单位圆盘
  扰动，不改变扰动族），每组扰动四角后**重解单应矩阵并复测全部区域**；
- 失败样本**计入失败比例，绝不静默丢弃**，并按原因计数：
  - `out_of_bounds`（越界）——扰动后角点超出图像范围；
  - `degenerate`（退化）——扰动后四边形共线 / 非凸 / 单应近奇异 / 残差过大；
  - `failed_geometry`（几何非法，按区域计）——该区域在扰动单应下自交、
    孔洞越界、顶点落在无穷远线等；
- 每个区域返回面积与周长的 **P5 / P50 / P95** 及**有效样本比例**
  （有效样本数 / 128，即前端所示“覆盖率”）；
- **有效样本比例低于 80% 时区间字段为 `null`**（`reliable=false`），
  并返回重新标定提示；前端同样隐藏区间并显示提示；
- 敏感性结果不落盘（会话 JSON 结构不变）；前端按“角点 + 矩形宽高 + 单位 +
  误差半径 + 全部区域几何”的指纹缓存结果，任一变化即**自动作废**。

响应示例（节选）：

```json
{
  "radius_px": 2.0,
  "sample_count": 128,
  "valid_samples": 126,
  "valid_ratio": 0.984375,
  "reliable": true,
  "message": null,
  "failure_counts": { "out_of_bounds": 1, "degenerate": 1 },
  "polygons": [
    {
      "id": "…", "name": "区域 1",
      "sample_count": 128, "valid_samples": 126, "valid_ratio": 0.984375,
      "reliable": true, "failed_geometry": 0,
      "area": { "p5": 1.971, "p50": 2.0, "p95": 2.031 },
      "perimeter": { "p5": 0.1782, "p50": 0.18, "p95": 0.1819 }
    }
  ]
}
```

面积 / 周长区间单位与标定单位（及其平方）一致；`polygons` 按会话中区域的
当前存储几何逐一给出。未上传照片或标定无效时返回 400。

## API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/sessions` | 创建会话 |
| GET | `/api/sessions/{id}` | 获取会话（标定 + 各多边形测量值） |
| POST | `/api/sessions/{id}/image` | 上传/替换照片（multipart，清空旧几何） |
| PUT | `/api/sessions/{id}/calibration` | 提交四角与实际宽高，返回 H 与全部区域复算结果 |
| POST | `/api/sessions/{id}/sensitivity` | 标定敏感性：请求体 `{"radius_px": 2.0}`（0–1000 px）；按当前标定几何生成 128 组可复现角点扰动，逐组重解单应并复测全部区域，返回各区域面积/周长的 P5/P50/P95、有效样本比例与失败计数（越界/退化/几何非法均计入）；有效比例 < 80% 时区间为 `null` 并附重新标定提示 |
| POST/PUT/DELETE | `/api/sessions/{id}/polygons[/{pid}]` | 新增 / 更新 / 删除区域（请求体可带 `holes`：`[{points:[…]}]`）；几何非法的新增/更新返回 **422** 且不覆盖服务端已存的最后有效结果；DELETE 集合路径清空 |
| GET | `/api/sessions/{id}/export` | 下载测量 JSON（attachment） |
| GET | `/api/health` | 健康检查（容器 HEALTHCHECK） |
